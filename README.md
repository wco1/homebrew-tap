# Mellow Homebrew tap

```sh
brew tap wco1/tap
brew install --cask mellow-kitty
```

**Mellow Kitty** — a Mac app: the whole Mellow Instagram planner in its own window, and a filmed tabby cat that lies on the window's edge, guards your focus timer and carries new posts to the Plan. macOS 14 or later, Apple silicon and Intel, notarised by Apple. Free. Page: https://www.mellow.world/cat

The cask downloads the same notarised DMG the page offers and verifies its SHA-256.
